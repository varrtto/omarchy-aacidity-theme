# Aacidity for Omarchy

A lemon-and-lime citrus theme: lemonade surfaces, ripe lime accents, deep olive text, and yellow folder icons.

![Aacidity theme preview](preview.png)

## Install

```sh
omarchy theme install https://github.com/varrtto/omarchy-aacidity-theme
```

## Backgrounds

Two original wallpapers are included. Cycle through them with `omarchy theme bg next`.

## Palette

| Role | Color |
| --- | --- |
| Background | `#f7f9e8` |
| Foreground | `#2a3418` |
| Lime accent | `#6a9a1a` |
| Selection | `#e8f0a8` |

Omarchy generates application themes from `colors.toml`.
